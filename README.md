# E-Commerce Sales Analysis & Dashboard | Microsoft Excel

## Project Overview

This project focuses on analysing an e-commerce sales dataset using Microsoft Excel to identify sales trends, product performance, regional performance, customer behaviour, discount patterns, and delivery efficiency.

The objective was to transform raw transactional data into meaningful business insights using data cleaning, Pivot Tables, and an interactive-style Excel dashboard.

## Objectives

- Analyse overall sales and revenue performance.
- Identify the best-performing product categories and regions.
- Understand monthly revenue trends.
- Identify top-performing products.
- Examine customer payment preferences.
- Evaluate the impact of discounts on transactions.
- Analyse customer ratings and delivery performance.
- Present key findings through a visual dashboard.

## Project Workflow

### 1. Data Cleaning & Preparation

Before starting the analysis, I performed initial data quality checks to ensure the dataset was suitable for analysis.

Tasks performed:

- Checked for duplicate records.
- Identified missing values.
- Checked for incorrect or inconsistent data formats.
- Reviewed column structures and data consistency.
- Prepared the dataset for further analysis.

### 2. Exploratory Data Analysis using Pivot Tables

Created 8 Pivot Tables to analyse different aspects of the business.

| No. | Analysis | Business Objective |
|---|---|---|
| 1 | Revenue by Category | Identify the highest revenue-generating product categories. |
| 2 | Revenue by Region | Compare revenue performance across different geographical regions. |
| 3 | Monthly Revenue Trend | Understand how revenue changes over time. |
| 4 | Top Products by Revenue | Identify the products generating the highest revenue. |
| 5 | Payment Method Analysis | Understand customer payment preferences. |
| 6 | Discount Analysis | Compare discounted and non-discounted transactions. |
| 7 | Customer Rating Analysis | Evaluate customer satisfaction through ratings. |
| 8 | Delivery Performance | Analyse delivery efficiency and performance. |

### 3. Dashboard Development

Developed an Excel dashboard to consolidate the analysis and present key business metrics and visualisations in a single view.

The dashboard aims to make important business information easier to understand and interpret without having to navigate through individual Pivot Tables.

### 4. Challenges & Limitations

During the dashboard development process, I encountered certain limitations with my available Excel version.

- **Slicers:** Unable to implement interactive slicers due to version limitations.
- **Date Grouping:** The available Excel version did not support the required Pivot Table date-grouping functionality for the monthly revenue trend.

Despite these limitations, I completed the analysis using Pivot Tables and available Excel visualisation features.
